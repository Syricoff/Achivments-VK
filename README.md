# VK Mini App «ЛАМПА 2026» 🚀

Геймифицированная платформа для участников лагеря студенческого актива **«Лампа 2026»** (Профком КГУ им. К.Э. Циолковского). Приложение встраивается в сообщество ВКонтакте и предоставляет систему рейтинга, выполнение ежедневных и разовых заданий с подтверждением фото/скриншотами, магазин мерча за баллы и полноценную панель администратора для организаторов.

  * Розовая карточка (`#F26B9A`, скругление 24px) с названием, периодичностью, описанием и наградой (`100 БАЛЛОВ`).

  * Интерактивные статусы: «Доступно», «На проверке», «Выполнено», «Отклонено» + модальные окна прикрепления скриншотов и сканирования QR-кодов.

## 🚀 Быстрый запуск

### Вариант 1. Запуск Mini App локально (Dev)

Frontend имеет встроенный движок Mock-данных с сохранением состояния в `localStorage`: приложение работает полноценно и мгновенно даже без развернутого бэкенда!

```bash
cd mini-app
npm install
npm run start
```
Приложение откроется на `http://localhost:5173/`.

### Вариант 2. Запуск Backend (FastAPI)

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Запуск начального заполнения БД (12 заданий, 5 товаров, участники)
python seed.py

# Запуск API сервера
uvicorn app.main:app --reload --port 8000
```
Swagger-документация доступна по адресу `http://localhost:8000/docs`.

### Вариант 3. Развертывание через Docker Compose (Production)

Перед запуском создайте `.env` в корне проекта и задайте реальные `VK_APP_ID`, `VK_APP_SECRET` и `ADMIN_VK_IDS`. Список администраторов указывается как JSON-массив числовых VK ID, например `ADMIN_VK_IDS=[123456,789012]`. Не оставляйте тестовый секрет из Compose.

Frontend собирается до развёртывания, а не внутри контейнера хостинга:

```bash
cd mini-app
npm ci
npm run build
cd ..
docker compose up -d --build
```

Каталог `mini-app/build/` должен попасть в репозиторий и на сервер вместе с кодом. Контейнер frontend — только лёгкий Nginx-сервер готовых файлов и не требует Node.js или сборки на хостинге.

При старте backend запускается `backend/seed.py`: он добавляет недостающие задания и товары, не создавая демо-пользователей и тестовые QR-коды. Повторный запуск безопасен: уже существующие задания и товары не дублируются.

## 🔒 Бизнес-правила

1. **Разделение Рейтинга и Баланса покупок:**
   При одобрении задания увеличиваются `rating_points` и `spendable_points`. При покупке в магазине списываются ТОЛЬКО `spendable_points`, поэтому позиция в «РЕЙТИНГЕ» никогда не падает из-за покупок.
2. **Сброс заданий по МСК:**
   Ежедневные задания проверяют отправку за текущие календарные сутки по часовому поясу `Europe/Moscow`. Единоразовые — за все время работы лагеря.
3. **Защита от Race Condition в магазине:**
   Покупка лимитированных товаров (например, «Сюрприз от организаторов» — 1 шт.) выполняется в транзакции с блокировкой строки (`with_for_update`).
4. **Панель Администратора:**
   Включает 5 вкладок: модерация очереди скриншотов, ручное начисление баллов (с кнопкой рандомайзера «Счастливчик дня»), генератор одноразовых QR-кодов («Сыщик»), учет выдачи мерча по кодам и редактирование заданий.
